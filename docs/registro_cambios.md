# Registro de Cambios

## Elementos de Configuración del Software (ECS)

Los elementos que forman parte del proyecto son:

- `src/index.html`: formulario de registro de clientes.
- `src/script.js`: lógica del sistema y validación del teléfono.
- `tests/test_validacion.js`: pruebas automatizadas.
- `package.json`: configuración para ejecutar las pruebas.
- `docs/README.md`: descripción del proyecto.
- `docs/manual_usuario.md`: instrucciones para el usuario.
- `docs/manual_tecnico.md`: información técnica.
- `docs/plan_pruebas.md`: planificación y resultados de las pruebas.
- `docs/registro_cambios.md`: historial de modificaciones.
- `.gitignore`: archivos y carpetas excluidos del repositorio.
