
# Manual de Usuario

## Gestor de Clientes

El sistema permite registrar clientes ingresando su nombre y teléfono.

### Funcionamiento
1. Ingresar el nombre del cliente.
2. Ingresar el teléfono.
3. Presionar el botón Registrar cliente.
4. El sistema muestra los datos ingresados.

En esta versión inicial, el teléfono todavía no cuenta con una validación de formato.
