# Manual de Usuario

## Gestor de Clientes

El sistema permite registrar clientes ingresando su nombre y número de teléfono.

### Funcionamiento

1. Ingresar el nombre del cliente.
2. Ingresar el número de teléfono.
3. Presionar el botón **Registrar cliente**.
4. El sistema verifica que el teléfono contenga únicamente números.
5. Si los datos son correctos, muestra la confirmación del registro.

### Validación del teléfono

A partir de la versión 1.1, el teléfono debe contener solamente números, sin letras, guiones ni espacios.

Si se ingresa un formato incorrecto, el sistema muestra el siguiente mensaje:

"Error: el teléfono solo debe contener números."

Si el teléfono es válido, el sistema confirma el registro del cliente.
